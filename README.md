# Дневник

Локальное веб-приложение для заметок и отметки учёбы по дням.
Чёрно-белый минимализм (цветными остаются только статусы), никаких внешних
зависимостей и сетевых запросов — данные не покидают ваш браузер.

## Запуск

Откройте `index.html` двойным кликом (или ярлык «Дневник» на рабочем столе).

Либо через локальный сервер:

```bash
python -m http.server 8080
# http://localhost:8080
```

## Календарь

- Навигация месяцами `‹ ›` и годами `« »`, выбор через сетки; `←`/`→` листают
  месяцы, `T` — сегодня, `F` — лента
- **Цвет ячейки = статус дня**: рамка и лёгкая заливка меняются на
  зелёный / жёлтый / красный; выбранный день инвертируется, но рамка остаётся
  цветной
- Кружок в ячейке циклично переключает статус: нет → зелёный → жёлтый → красный
- **Полоска внизу ячейки** — прогресс к цели по времени за этот день
- Точка — есть заметки, ★ — есть закреплённые

## Неделя и статистика

- **Полоска недели** над календарём: 7 дней выбранной недели с цветом статуса
  и временем учёбы, клик — открыть день
- **Серия дней** — непрерывная череда отмеченных дней (`СЕРИЯ 4 дн.`)
- **Статистика месяца**: часы, отработанные дни, среднее, количество заметок,
  счётчики зелёных/жёлтых/красных дней

## Панель дня (справа)

- **Учёба**: часы и минуты вручную + кнопка «Сброс»
- **Таймер**: `Старт` / `Пауза` / `Продолжить` — идущие секунды автоматически
  записываются в минуты этого дня (сохраняется при перезагрузке страницы)
  - `−5 с` / `+5 с` — убрать или прибавить 5 секунд (итоговые минуты
    синхронизируются, в том числе вниз до целой минуты)
  - `Обнулить таймер` — обнуляет только счётчик секунд, **накопленное время
    остаётся в цели и в часах дня**
- **Цель в день** (часы **и** минуты, по умолчанию 2 ч 00 м): полоска
  прогресса и метка «ЦЕЛЬ ДОСТИГНУТА»
- **Статус дня**: четыре кружка
- **Заметки**: добавление, изменение, удаление, **закрепление ★** (важные
  всплывают наверх и помечаются звездой в календаре)

## Темы оформления (9 вариантов)

Кнопка **«Тема»** в шапке (или клавиша `G`) открывает выбор из девяти стилей:

| Тема | Стиль |
|---|---|
| Чёрно-белый | классический монохром (по умолчанию) |
| Ночь | тёмно-синий, узор звёздного неба |
| Океан | глубокий бирюзовый, узор волн |
| Лес | тёмно-зелёный, узор ёлочек |
| Закат | тёплый оранжевый, узор кругов солнца |
| Сакура | сливовый, узор лепестков |
| Лаванда | фиолетовый, узор мыльных пузырей |
| Бумага | светлый песочный, узор клетки |
| Мгла | светлый холодный, узор штриховки |

Каждая тема меняет палитру целиком — фон, панели, рамки, акценты кнопок и
статусы, — сохраняя читаемость инверсии выделенного дня. Выбор темы хранится
в настройках и переживает перезапуск; при экспорте/импорте JSON тоже
переносится (неизвестные значения отбрасываются белым списком).

**Безопасно:** узоры — это небольшие SVG, встроенные в CSS в виде `data:`
URI. Ни при установке темы, ни при работе приложения не выполняется ни
одного сетевого запроса — это подтверждает CSP (`img-src 'self' file: data:`),
который запрещает всё прочее.

## Лента, обзор и навигация

- **Лента** (кнопка в шапке или `F`) — все заметки по дням, фильтр по тексту,
  закреплённые помечены ★, клик — переход к дню
- **Поиск** — по всем заметкам с переходом к нужному дню
- **Обзор года** (кнопка у статистики или `Y`) — тепловая карта года:
  квадрат дня окрашен по статусу или по интенсивности часов, итоги года,
  лучший день и среднее по дням недели; клик по квадрату открывает день
- **Переход к дате** — поле в шапке: мгновенно перейти на любой день

## Управление

| Клавиша | Действие |
|---|---|
| `←` `→` | предыдущий / следующий месяц |
| `T` | сегодняшний день |
| `F` | лента заметок |
| `Y` | обзор года |
| `G` | выбор темы оформления |
| `N` | новая заметка для выбранного дня |
| `1` – `4` | статус дня: нет / зелёный / жёлтый / красный |
| `Ctrl+Z` | отменить последнее действие |
| `?` / `H` | справка по клавишам |

Кнопка **«Отменить»** в подвале возвращает предыдущее состояние заметок и
отметок (журнал из 40 шагов).

## Безопасность и приватность

- Кнопка **«Скрыть»** — размывает тексты заметок на экране (передышка на
  публике), возвращается обратным кликом
- Кнопка **«Экспорт текста»** — сохраняет все заметки в читаемый `.md` файл
  (JSON-копия — «Экспорт JSON»)

## Android-версия

В папке `android/` — **нативное** Android-приложение для Android 10+
(Java + системные виджеты + SQLite, без WebView и без Gradle):

- **Ноль разрешений**: нет даже `INTERNET` — у приложения нет доступа в сеть
- Данные дневника хранятся только в SQLite папки приложения;
  `allowBackup="false"` — не уходят в облачный бэкап
- Тот же пакет, что у веб-обёртки: устанавливается поверх неё как обновление
- Календарь, панель дня (учёба, таймер, цель, статусы, заметки со ★),
  серия и статистика года, поиск, 9 тем, экспорт/импорт JSON
- Формат экспорта совместим с веб-версией — копия переносится в обе стороны
- Сборка: `powershell -ExecutionPolicy Bypass -File android\build-native.ps1`
  (aapt2 + javac + d8 + apksigner), подробности — в `android/README.md`
- Логика и UI-потоки покрыты 34 автотестами (Robolectric, `android/tests/`),
  запуск: `mvn -f android\tests\pom.xml test`

## Данные

- Заметки: `localStorage` → `diary.entries.v1`
- Время и статусы: `diary.marks.v1`, настройки цели: `diary.settings.v1`,
  таймер: `diary.timer.v1`
- Экспорт / импорт резервной копии в JSON, очистка с подтверждением
- Никаких серверов, аналитики, внешних шрифтов и скриптов

## Безопасность

- **Content-Security-Policy** запрещает любые сетевые запросы и inline-код —
  работают только локальные файлы приложения
- Весь текст выводится через `textContent`, записи с `<script>`/`<img onerror>`
  отображаются как обычный текст (защита от XSS)
- Данные из `localStorage` и импортируемых файлов валидируются и обрезаются
  (структура, ключи дат, длина, диапазоны чисел, допустимые статусы)
- Опасные операции (удаление, очистка, импорт) требуют подтверждения
